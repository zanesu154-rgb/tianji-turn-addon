# 真实样本回归体系

本文只描述结构。它不加入第三方包，不改产品源码，也不改 `test/run-tests.js` 或 `.github/workflows/tests.yml`。

公开 CI 已经覆盖合成数据。真实附加包和地图留在另一层，不让公开测试依赖私人文件。

## 两层

| 层 | 材料 | 何时运行 | 缺材料时 |
| --- | --- | --- | --- |
| 公开 | `test/fixture`、`test/make-world.js` 生成的合成存档 | `Tests`：pull request、推送到 `main`、`workflow_dispatch` | 不依赖私人文件，必须跑完 |
| 真实样本 | 私有仓库里的原包，或大于 100MB 时的 Release 附件 | 单独入口。环境变量未设置时不运行 | 未设置环境变量：明确跳过。已设置但不满足下面的入口条件：失败 |

公开工作流不克隆私有仓库，不下载第三方原包，也不把通过数量写进 YAML。真实样本层以后用自己的脚本，不塞进 `node test/run-tests.js`。

## 首个样本：基岩版重塑

选它是因为历史档案里它被反复重转，并且同时踩过误提取、多语言字典和规则误伤。这是样本角色，不是「今天再转一次必然得到某次历史 lang」的证明。助手当时说的「提取结果没变」保持为历史声明。

2026-11-22 核对私有仓库 `origin/HEAD`：`ADD-ON/基岩版重塑 Bedrock Reimagined/` 只有 `notes.md`（4,705 字节）。该目录没有 `.mcaddon` 或 `.mcpack`。公开仓库 `main` 也没有这个原包。笔记仍写着回归检查项「待整理」，没有附件名、字节数或 SHA-256。

私有仓库 Release `Sample` 上有附件 `ADDON_Bedrock.Reimagined.mcaddon`（88,057,900 字节）。它不在 git 树里，笔记也没有登记它。在登记写出文件名和 SHA-256 之前，不下载、不转换、不用其它包或相似文件名代替。

它是附加包，不是世界存档。世界再转换、告示牌和命令方块不放进这个样本。那些继续由合成存档和私人 `test/world-fixture` 负责。

## 第一期检查什么

哈希与登记一致之后，第一期只锁少数不变量。不把整份 `zh_CN.lang` 提交到公开仓库，也不把某一次转换的键数量当成永久期望。

建议的不变量：

- 多语言脚本字典：同一路径各语言共用键，译文进各自 lang，而不是合成一条。
- `event entity` 这类命令不被当成玩家可见文本。
- 短变量规则不得删掉正常句子。历史记录是收紧之前曾误伤 4 条；期望写成「正常句子仍在」，不写成「误伤 4 条」本身。
- 再次转换时，放回的译文不被原文覆盖，不再建一套重复键。
- 改了会坏的 ASCII HUD 字段不进入待提取列表。

每条不变量旁注证据等级：用户确认的现象、用户确认的样本、历史修复声明、当前源码、公开测试已覆盖。历史声明单独列出，不升格成当前通过。

笔记里那一长串修复编号是索引，不是第一期的断言清单。一次只加已经能用输入输出说清的检查。

## 文件放哪

- 原包：继续留在私有样本库或 Release。公开仓库不提交 `.mcaddon`、`.mcpack`、`.mcworld`。
- 期望：以后在公开仓库放一小份文本夹具，只含键名、若干句子和「必须出现 / 必须不出现」。整包输出留在运行目录，不入库。
- 样本登记：私有仓库笔记写下附件名、字节数和 SHA-256。登记是开始转换的前提，不是转换之后补记的结果。

## 怎么跑

真实样本入口只读一个环境变量，变量指向样本根目录。公开 `Tests` 不设置它，也不申请私有仓库权限。

| 条件 | 结果 |
| --- | --- |
| 环境变量未设置 | 打印明确的跳过说明，退出码 0 |
| 环境变量已设置，但目录不存在 | 报错，退出码非 0 |
| 登记中的样本文件不存在、文件打不开或损坏 | 失败，不得记为通过 |
| 文件的 SHA-256 与私有样本登记不一致 | 失败，不得记为通过 |
| 哈希与登记一致 | 才开始转换，然后执行第一期不变量 |

未登记哈希时，没有「一致」可比较，转换不开始。失败时退出码非 0，日志写明是缺文件、损坏还是哈希不符。

这个入口不加入现有 `Tests` 工作流。公开 CI 保持现在的三处触发和 `contents: read`。真实样本运行由持有原包的人在本地或私有环境执行。

## 这一期不做

- 不批量转换基岩版重塑或其它样本。
- 不把五号化合物、YTAUN、符文工艺、破碎之径写进第一期断言。它们留在后续名单里：五号化合物有用户点名的误提取数量，符文工艺是 HUD 脚本损坏，破碎之径是世界存档。
- 不把历史测试总数当作当前套件的计数。
